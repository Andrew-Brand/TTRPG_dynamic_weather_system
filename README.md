# TTRPG dynamic weather system
A dynamic weather system designed to shift through weather patterns naturally, day by day.

Is this the most autistic thing I've done? Potentially.

## General function
The model takes an input season, as well as region temperature and humidity (inspired by the biome pyramid model)

Valid inputs for each variable are given below (case-sensitive):
**SEASON**
- spring
- summer
- autumn
- winter

**TEMPERATURE**
- tropical
- subtropical
- temperate
- subpolar
- polar

**HUMIDITY**
- humid
- subhumid
- semiarid
- arid
- hyperarid
